# Archive

本目录用于保存已经退出主线结构、但仍需要保留作参考的历史代码和本地工具产物。

当前归档内容包括：

- `JM-Aura/`：旧版 FastAPI + Vue 3 项目
- `JMComic-Crawler-Python-master/`：上游/历史 Python 工具链参考
- `.superpowers/`：本地代理与脑暴工具输出
- `.trae-html-share-packages/`：本地 HTML 分享打包产物
- `ai-agent-handoff-2026-07-09/`：历史交接文档产物

使用原则：

1. 当前主线开发请以仓库根目录为准。
2. 若需对照旧实现、迁移逻辑或追溯历史，再进入本目录查阅。
3. 本目录中的内容默认不作为当前版本发布入口，也不作为部署根目录。
